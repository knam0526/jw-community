# CAFE ING 음료교환권 (2,000원)

한신대 카페아이엔지(CAFE ING) 음료교환권입니다. 샘플 쿠폰 구성을 기준으로 아래처럼 바꿔 두었습니다.

| 구분 | 내용 |
| --- | --- |
| 상단 | cafe ing 로고 이미지 |
| 중단 | 음료교환권 + **(2,000원)** (세로 가운데) + 음료 사진 |
| 하단 1줄 | 카페아이엔지 CAFE ING |
| 하단 2줄 | 경삼관, 장준하통일관점 사용가능 |
| 삭제 | 유효기간, 하단 우측 로고 |
| 1매 크기 | **가로 60mm × 세로 45mm** |
| 인쇄 | **A4 용지 15매** (3열 × 5행) |

## 바로 인쇄하기

1. [`output/CAFE_ING_음료교환권_2000원_A4_15매.pdf`](output/CAFE_ING_음료교환권_2000원_A4_15매.pdf) 를 엽니다.
2. 용지 크기 **A4**, 배율 **100%** (맞춤/맞춤 축소 해제), 양면 아님.
3. 테두리를 따라 가로 6cm, 세로 4.5cm로 자릅니다.

브라우저에서 보거나 다시 인쇄하려면 [`index.html`](index.html) 을 연 뒤 **인쇄 / PDF 저장**을 누르면 됩니다.

## 다시 만들기

```bash
python3 generate.py
```

한글 폰트는 `fonts/` 의 나눔고딕·나눔스퀘어를 사용합니다.
